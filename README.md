🍷 **Wine Quality Prediction (Machine Learning)**

This project predicts the quality of red wine using Machine Learning.
The goal is to classify wine as either Good Quality or Bad Quality based on chemical properties.

📌 **Project Description**

Used the Red Wine Quality dataset

Performed data analysis and visualization

Converted the wine quality score into binary classes (Good/Bad)

Trained a Random Forest Classifier

Achieved high prediction accuracy

🧪 **Dataset**

Total records: 1599

Total features: 12

Target column: quality

📊 **Work Done**
✔ Data Collection

Loaded the dataset and inspected rows, columns, and missing values.

✔ Data Analysis

Plotted:

Count of each wine quality rating

Relation of acidity and citric acid with quality

Correlation heatmap across all features

✔ Data Processing

Separated features and labels, converted quality scores into binary values, and split the data into training and testing.

✔ Model Training

Used Random Forest Classifier to train the model.

✔ Model Evaluation

Achieved around 92.5% accuracy on test data.

✔ Prediction

Built a simple system that predicts whether a given wine sample is Good or Bad based on input values.
